# Trump 财务交易分析仪表板

基于 **OGE Form 278-T**（美国政府伦理办公室财务交易申报表）的交互式数据分析仪表板，对 Donald J. Trump 2026年1月至3月期间的证券交易进行可视化分析。

## 数据来源

- **文件**: OGE Form 278-T (Updated February 2024)
- **申报人**: Donald J Trump
- **提交日期**: 2026年5月8日
- **交易期间**: 2026年1月 – 2026年3月
- **总页数**: 113页交易清单

## 数据概览

| 指标 | 数值 |
|------|------|
| 总交易笔数 | 3,642 |
| 出售 (Sale) | 2,574 笔 (70.7%) |
| 购买 (Purchase) | 1,068 笔 (29.3%) |
| 涉及公司 | 800+ |
| 预估交易总额 | ~$18 亿 |
| 交易方式 | 95%+ UNSOLICITED（非主动推荐） |

## 核心发现

1. **大规模清仓式出售**: 出售金额约 $17.7 亿，购买仅 ~$3,500 万，净撤出 ~$17.3 亿
2. **科技巨头集中减持**: Meta、Amazon、Microsoft 各出现 $5M–$25M 超大额出售
3. **指数化分散持仓**: 800+ 家公司横跨全行业，持仓模式类似标普500指数基金
4. **就职合规处置**: 与联邦高级官员利益冲突回避要求一致的系统性资产清理

## 功能

- **KPI 概览**: 核心指标一目了然
- **出售/购买对比**: 并排展示两组交易数据
- **售出详细分析**: 金额分布、行业分布、TOP 20 标的、交易方式
- **购买详细分析**: 金额分布、行业分布、 TOP 20 标的、交易方式
- **双向交易分析**: 同一标的既买又卖的公司列表
- **时间线分析**: 周度交易量趋势
- **高频交易标的**: 重复交易最多的公司
- **Mega Cap 专项**: 超级大盘股交易情况
- **合规说明**: OGE 制度与利益冲突评估

## 技术栈

- **纯前端**: HTML + CSS + JavaScript
- **图表库**: [Chart.js](https://www.chartjs.org/) 4.4.7
- **无构建工具**: 直接打开 `index.html` 即可运行

## 使用方法

```bash
# 直接在浏览器中打开
open index.html

# 或使用本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 响应式设计

- 桌面端 (>1100px): 多列布局
- 平板端 (768–1100px): 双列布局
- 移动端 (<768px): 单列布局，表格可横向滚动
